## Reflection

Practices such as documentation, diagrams, automated testing, version control, and peer reviews are important for building shared understanding in development teams. Documentation and diagrams help explain how code works and how different parts of the system interact. Automated tests ensure that the code behaves correctly and make it easier to detect bugs when changes are introduced. Version control systems like Git allow developers to track changes and collaborate effectively. Pair programming and peer reviews also improve code quality, because multiple developers can discuss solutions, share knowledge, and maintain consistent coding practices. Together, these practices help teams maintain shared code ownership and improve long-term maintainability.
